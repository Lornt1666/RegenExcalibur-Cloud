# AutoHouse Ω v450 — Permit / Geotechnical / Authority Closure

**SCHEMATIC — NOT FOR CONSTRUCTION — UNSEALED — PROFESSIONAL / AHJ REVIEW REQUIRED.**

v450 converts permit-readiness from a label into a fail-closed evidence state machine. The full evidence package contains 3,479 machine-readable permit, professional-licensing, geotechnical, survey, manufacturer and AHJ parameter/evidence records; the repository keeps the executable core and compact governance contract.

## Responsibility allocation

- `licensing_documentation_accountable_party = HOMEBUILDER`
- `master_document_control_accountable_party = HOMEBUILDER`
- `digital_document_coordination_system = REGENEXCALIBUR / AUTOHOUSE`

This allocation is document governance only. It does not transfer the owner's statutory Safety Codes responsibility, professional authentication/field-review obligations, Alberta Land Surveyor authority, restricted trade obligations, or AHJ/Safety Codes Officer authority.

## Release levels

`SCHEMATIC → PERMIT_SUBMISSION_FEASIBLE → PERMIT_SUBMITTED → PERMITS_ISSUED_SCOPE_LIMITED → CONSTRUCTION_RELEASE_FEASIBLE → CONSTRUCTION_RELEASE_AUTHORIZED → OCCUPANCY_READY → OCCUPANCY_AUTHORIZED → AS_BUILT_CLOSEOUT`

`AUTHORIZED` states require independently verifiable, non-synthetic authority receipts. Self-issued, AI-generated, builder-generated, manufacturer-generated or RegenExcalibur-generated authority evidence cannot satisfy the gate.

## Alberta reference adapter — researched 2026-08-22

The reference adapter records the National Building Code – 2023 Alberta Edition and National Fire Code – 2023 Alberta Edition in force May 1, 2024; NECB 2020 in force May 1, 2024 where applicable; NPC 2020 in force April 1, 2023; CSA C22.1-24 Canadian Electrical Code, 26th Edition in force April 1, 2025; and CSA-B149.1:25 in force March 1, 2026. Every live project must re-bind its exact AHJ, permit application date, transition provisions, STANDATA, zoning/development rules and project classification.

## Professional path

Where professional involvement is triggered, v450 models Schedule A / B / C1 / C2 / C3 responsibility flow, APEGA corporate Permit to Practice evidence, authenticated professional work products, delegated design and professional closeout. AI results remain software/tool output until appropriately checked and, where required, authenticated and validated by the licensed professional.

## Geotechnical / survey path

The full package tracks site geology/geomorphology, boreholes/test pits/CPT, groundwater, soil classification, strength/deformation, settlement/consolidation, permeability, frost, sulphate/corrosivity, shallow/deep foundations, earthworks, shoring/dewatering, slopes/retaining, seismic/geohazards and field review. Survey evidence covers title/legal description, easements/ROW, survey control/datum, boundary monuments, topography/utilities, layout, foundation as-built, RPR and lot-grading closeout.

Municipal examples such as Edmonton and Calgary are precedents for triggers and evidence classes, not universal province-wide minimums.

## Manufacturer / alternative-solution path

Critical proprietary products resolve product identity and traceability, intended use/function, current installation instructions, code path, current certification/CCMC evidence, limitations, delegated/professional review and AHJ acceptance where required. A CCMC evaluation is not treated as automatic local approval.
